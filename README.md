# Ramble

Ramble is an interactive walking-tour demo built with Expo and React Native.

The demo is one self-guided walk, **The Lantern Loop**, through the sample neighborhood of Port Meridian. You start under the ferry clock, move stop to stop up the hill, and finish on the bench that looks back over the route. Each place stays closed until you arrive. On a desktop, **Walk** carries you along the map so you can play the tour without leaving the chair.

## Run the demo

```bash
npm install
npm run web
```

Open [http://localhost:8081](http://localhost:8081).

`npm start` opens the Expo dev tools if you want a device or simulator instead of the browser.

## What you can do

- Start the ramble and read the first stop.
- Walk to each of the six stops and watch the route fill in.
- Mark the thing you were asked to notice.
- Tap a stop you have already reached to hear it again.
- Finish the loop and ramble it again.

Port Meridian is sample writing for the demo, not a real city.
